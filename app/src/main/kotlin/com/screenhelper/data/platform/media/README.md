# 系统媒体能力

PetSoundPlayer 是应用内共用的单播放器。事件调用 play，先释放旧 MediaPlayer，再异步准备新 MP3；准备回调只允许当前实例开始，避免连续事件让已过期的声音继续播放。播放完成、错误、熄屏、桌宠服务结束和关闭音效时释放播放器。默认遵循设备媒体音量，不强制修改系统音量，不请求麦克风权限。

全局开关由 SettingsRepository 的独立 DataStore 布尔键保存，旧版本没有这个键时默认开启。开关即时生效，不依赖模型设置的“保存设置”，关闭时停止正在准备或播放的音频。提醒走统一业务回调，即使桌宠关闭也可播放；通知本身静音，避免系统通知声叠加。

ScreenCaptureService 负责用户授权的单帧/连续 MediaProjection。持续共享每 5 秒采一帧，最近三帧由业务层送往视觉模型；停止或锁屏时清空缓存。SoundFlowTest 使用 Android 原生解码和真实播放器状态验证音频，不访问网络。
