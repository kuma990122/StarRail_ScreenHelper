# 本地持久化

Room 保存角色、消息、好感、去重事件、待办、明确记忆和每日回忆。DataStore 保存当前角色和模型配置；Key 经 Keystore AES-GCM 加密，随机 IV 随密文存储。禁用系统备份，避免凭证与设备密钥分离恢复。

图片先复制并限制输入文件 15MB，再按尺寸采样，导入私有 images 目录。录音使用 cacheDir。当前验证版尚未做废弃图片的引用回收，长期大量导入可能增加磁盘占用。Schema 导出到 app/schemas，数据库升级应添加迁移，不能使用破坏性迁移掩盖问题。

0.2 将数据库升级为版本 2；`MIGRATION_1_2` 只新增每日回忆表，保留旧角色和历史。每日回忆按角色、日期建立联合主键，摘要和归档路径写入 Room；完整当日消息另存私有目录 `daily-archives/*.json.gz`，原消息保留。归档服务用源消息哈希避免重复写入。

`PetAssets` 将内置 WebP 安装到私有 `mimi-motion-v1` 目录，按状态随机选择对应动画。屏幕互动连续帧只在内存保存，不进入这些目录；单次主动截图仍可作为聊天附件保存。
