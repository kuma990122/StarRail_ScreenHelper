# 桌宠规则

`PetPolicy` 是无 Android 依赖的纯规则，`PetService` 负责窗口、手势和动画。

- 午间 12:00–13:59、夜间 21:00–06:59，30 秒无交互进入睡眠。
- 亮屏问候使用单调时钟，冷却 10 秒；提醒期间保留提醒优先级。
- 单击等待系统双击时间窗后使用 TouchReplyPolicy 随机输出本地人设短句（源于 assets/skills/mimi.md），不发送 API；双击跳转主页，提醒期间跳转备忘。
- 拖动开始随机选一次拖动动画，放开恢复待机；接近左、右、下边缘时吸附并切换相应动画。下边缘优先。
- 桌面角色窗口边长为屏宽 32%，下方贴边为 22.4%；应用前台为屏宽 15% × 屏高 15%。独立气泡为屏宽 19.2% × 9.6%，下方再乘 70%。尺寸统一由 windowSize/bubbleSize 计算。
- nextMemo 按到期时间、ID 稳定排序，返回最早的未完成待办，包含逾期待办；无待办返回 null。
- 永劫回归按本地周一零点起经过的秒数显示，每秒刷新；原文档毫秒口径以本次需求的秒口径覆盖。

测试：`IterationPolicyTest`；跨应用手势与贴边：`OverlayFlowTest`。
