# 屏幕互动

`ScreenInteractionService` 负责三帧视觉评论的角色上下文、提示词、输出长度与 token 上限。Android 授权及采集由 `data/platform/media/ScreenCaptureService` 管理。

用户在对话页主动开启 → 系统 MediaProjection 授权 → 前台通知 → 每 5 秒最多采一帧 → 三槽滑动窗口 → 同一条多图片消息 → 视觉 API → 桌宠气泡。

持续采集长边最多 720 像素、JPEG 质量 75，仅保留内存缓存，不生成屏幕历史文件。已有请求未结束时跳过推理，不排队；文本对话忙碌时也跳过。输出最多 96 tokens，气泡最多 40 字。新对话或提醒优先，不覆盖它们。

锁屏时清空帧并取消推理，亮屏后重新积累。停止、系统撤销或 API 错误会结束服务并清空缓存，错误不自动重试。再次开启需重新授权。三帧齐全后最多每 5 秒请求一次，实际由上一次推理耗时限制；真实模式会持续产生服务商费用。

配置独立视觉模型，或确认文本模型支持图片。普通纯文本 DeepSeek 配置不能自动获得图像能力。离线演示只验证采集、调度和气泡流程；接口单测用 MockWebServer 验证三图顺序，不访问收费服务。屏幕上的第三方应用可能限制录屏；竖横屏切换建议停止后重新授权。
