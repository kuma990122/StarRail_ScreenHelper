# 对话编排

ContextBuilder 组合角色、关系阶段、最多 8 条记忆和有限历史。历史限 20 条、合计约 7000 字符；这是字符预算而非精确 token 预算。当前消息最多 4000 字。每次网络请求默认限制输出 512 tokens。

模型输出约定情绪后缀 [[emotion:happy]]；解析器隐藏后缀并映射立绘。关系通过提示词调整表达风格，不修改模型权重或潜变量。

ConversationService 防止并发重复发送，约 45ms 更新一次 UI；取消保留已收到内容。进程中断后 streaming 记录在下次初始化时标记 interrupted。没有后台自动重试。
