# 共同记忆与每日回忆

`MemoryService` 保留原有“记住：”显式事实记忆；`DailyMemoryService` 按角色及本地日期生成简要回忆，两者独立。

数据流：Room 当日非生成中消息 → 用户话题提取 → `daily_memories` → `MemoryViewModel` → 珍贵回忆页面。完整文本同时写入应用私有目录 `daily-archives/*.json.gz`，保留原始 Room 对话，避免历史页面丢失。

摘要规则为本地提取，不花费 API 额度：只采样用户消息，忽略助手推测；取首句，单条最多 36 字；去重后均匀选最多 5 个话题，总长度不超过 220 字。移除链接、邮箱和长数字，省略后续细节。图片消息无文字时记为共同看图。它不是模型语义概括，长句开头可能仍保留部分细节，后续可新增可选语义摘要提供器。

每日午夜用非精确系统闹钟触发，进程存活时跨日检查，启动及重启/时间变更补归档。系统省电、关机或强制停止可能延后执行；恢复应用后补齐。手动按钮生成今天的回忆。互斥锁避免并发归档，源内容 SHA-256 避免重复写入；临时文件完成后重命名，再更新数据库，清理上一版压缩包。

Room v1 → v2 仅新增每日回忆表，不清空原数据。设备测试检查迁移、压缩内容、幂等、更新及历史保留。
