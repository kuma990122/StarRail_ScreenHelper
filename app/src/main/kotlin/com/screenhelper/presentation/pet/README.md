# 桌宠窗口与动态立绘

PetService 是用户开启的前台服务，通过 WindowManager 分别创建角色窗口与不接收触摸的气泡窗口。桌面角色边长为屏宽 32%（旧 40% 再缩小 20%），下方贴边再乘 70%。应用前台角色窗口严格为屏宽 15% × 屏高 15%。气泡宽为屏宽 19.2%，高为其一半（旧窗口缩小 20% 后再缩小至 60%），下方再乘 70%。尺寸始终从屏幕计算，切换前后台不累积缩放。

单击等待系统双击时间窗后随机输出本地人设短句，无输入框或网络调用；双击主页，提醒期间双击备忘。拖动开始随机选拖动素材，放开恢复待机或左/右/下贴边。主页通过 PetHost 仅传递屏幕坐标，角色固定在原立绘中心，拖动保留动画但不改变位置；其他页面保留自由拖动。原主页 Compose 立绘已移除，关闭桌面陪伴时不显示角色。退出应用恢复桌面坐标及贴边状态。亮屏问候冷却 10 秒；睡眠时段 30 秒无互动后睡觉，点击唤醒。提醒显示 10 秒，单击不覆盖提醒。

tools/portrait_bounds.py 使用 Pillow 逐帧取 alpha 并集，生成同名 .bounds，安装时随 WebP 复制。渲染器在后台读取该元数据，将可见区域完整适配窗口，按左/右/下对齐，消除素材透明外边距与居中适配留白。不会裁掉不同动画帧的有效像素，也不会在运行时逐帧扫描。

PortraitAssetRenderer 后台解码，悬浮窗长边最多 512px，页面最多 1024px。WebP 使用 Android 9+ AnimatedImageDrawable，GIF 使用 Movie；离屏和熄屏暂停动画，关闭服务释放资源。25 个内置文件不同时解码。迷迷按行为选素材，其他角色使用自己的中性立绘。

MascotArt 仅作缺图及解码期间回退。素材见 assets/mimi/README.md。状态写入无障碍描述，使设备测试能观察睡眠和醒来，不需要调试后门。OverlayFlowTest 验证单击、双击、贴边、亮屏冷却及真实等待 30 秒睡眠；纯规则见 IterationPolicyTest。

Android 11+ 使用绑定默认显示器的 TYPE_APPLICATION_OVERLAY WindowContext 获取实时窗口度量，并监听显示变化与配置变化；折叠/展开后重新计算尺寸和可拖动边界。屏幕物理左上角为坐标原点，忽略系统栏适配内边距，拖到顶部时窗口 y=0，立绘可见区域同时顶部对齐。拖动跨尺寸变化时重新建立手势原点，避免旧坐标限制范围。设备测试分别切换 1800×1920 和 1080×2340 检查顶部。

亮屏问候、单击、拖动起始、左右贴边和睡眠状态进入会触发 PetSoundPlayer。每个事件只触发一次，不按动画帧或每秒轮询重复播放；双击导航不额外产生单击音效。全局开关与音效映射见 data/platform/media/README.md 和 res/README.md。
