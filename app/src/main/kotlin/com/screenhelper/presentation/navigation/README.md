# 主页导航与浮窗锚点

HomeScreen 顶部显示“逐火之旅”，右上角 Switch 控制桌面陪伴，不再显示云端/离线标签和底部重复开关。

主页不解码第二份迷迷立绘：透明定位区域通过 onGloballyPositioned 上报原立绘的屏幕中心；PetHost 使用 StateFlow 发布纯坐标，页面销毁清除锚点，MainActivity onStart/onStop 标记前后台。PetService 将唯一角色窗口固定于此，应用内尺寸为屏宽、高各 15%。切到其他标签解除固定。角色不会阻挡顶部开关或底部导航。

每个 Activity 和主页定位区域分别持有不引用页面的所有权标记。配置变化重建时，旧页面只能撤销自己的可见状态和坐标，不会清除新页面已经提交的锚点。

“下一件待办”显示最早未完成事项的标题与到期时间，标题最多两行，超长省略；空列表显示“暂无待办”。逾期未完成事项仍优先展示，点击进入备忘页面。
